## 📌 نبذة عامة

**Network Sniper Pro** هي أداة رسومية احترافية ومتطورة تعمل على أنظمة لينكس، صُممت لتوفير مراقبة عميقة للشبكة، وإدارة ذكية للباندويث (سرعة الإنترنت)، بالإضافة إلى ميزات التدقيق الأمني. تم بناء الأداة بالاعتماد على مكتبات قوية مثل `scapy` و `iptables`، لتوفر لمديري الشبكات والباحثين الأمنيين تحكماً مطلقاً في الشبكات المحلية.

## 🚀 الميزات الرئيسية

* **استكشاف متقدم للأجهزة:** استخدام `Nmap` لاكتشاف أنظمة التشغيل، الشركات المصنعة، وتتبع الأجهزة المتصلة بالشبكة في الوقت الفعلي.
* **محرك قطع اتصال ذكي:** يستخدم 3 استراتيجيات مختلفة وفعالة لعزل الأجهزة:
  * **القطع العادي (ARP Spoofing):** الطريقة الكلاسيكية لتعطيل الإنترنت على الشبكات المحلية.
  * **هجوم طرد الشبكة (Deauth Attacks):** للشبكات المفتوحة أو المعزولة (AP Isolation) باستخدام بروتوكول IEEE 802.11.
  * **حجب النظام (Iptables):** قطع وحجب الحزم على مستوى الكيرنل (Kernel-level) عندما تكون أنت موزع الإنترنت (Hotspot).
* **القائمة السوداء الدائمة (Persistent Blacklist):** نظام ذكي يراقب الشبكة باستمرار، وإذا عاد الجهاز المقطوع للاتصال أو غيّر عنوان الـ IP الخاص به، تقوم الأداة بقطعه تلقائياً مرة أخرى.
* **وضع الألعاب (Game Mode):** ميزة تسمح لك بتخصيص النسبة الأكبر من سرعة الإنترنت لجهازك وخنق السرعة عن باقي الأجهزة لضمان (Ping) منخفض وتجربة لعب سلسة.
* **فاحص المنافذ (Port Scanner):** أداة متكاملة لفحص منافذ TCP/UDP لاكتشاف الثغرات والخدمات المفتوحة على الأجهزة.
* **القائمة البيضاء (VIP Whitelist):** حماية أجهزتك المهمة (مثل التلفاز الذكي أو جهازك الشخصي) من القطع بالخطأ أو من قيود السرعة في وضع الألعاب.
* **لوحة إحصائيات حية (Dashboard):** واجهة ديناميكية تعرض إجمالي الأجهزة، الأجهزة المقطوعة، والأجهزة المحمية في الوقت الفعلي.
* **بحث وفلترة ذكية:** شريط بحث سريع للبحث عن طريق الـ IP، الماك أدرس، اسم الجهاز أو الشركة المصنعة.
* **واجهة عصرية وتخصيص الألوان (Dynamic Theming):** وضع نهاري/ليلي مع إمكانية تغيير ألوان التطبيق باستخدام مكتبة `customtkinter`.

## 🛠️ التقنيات المستخدمة
* **واجهة المستخدم:** `customtkinter` (واجهة حديثة وسريعة).
* **الشبكات والحماية:** `scapy` (بناء وتحليل الحزم)، `Nmap` (الفحص)، `iw` و `iptables` (التحكم العميق بالشبكة في لينكس).
* **قواعد البيانات:** `SQLite3` لحفظ السجل التاريخي للأجهزة، وملفات `JSON` لإدارة الإعدادات.

## 📦 التثبيت والاستخدام

**المتطلبات الأساسية:**
نظام تشغيل مبني على Linux (ينصح بـ Debian/Ubuntu/Kali) و Python 3.8+

```bash
# 1. نسخ المستودع
git clone https://github.com/YourUsername/NetworkSniperPro.git
cd NetworkSniperPro

# 2. تثبيت الحزم والمتطلبات الأساسية للنظام
sudo apt-get update
sudo apt-get install nmap aircrack-ng iptables

# 3. تثبيت مكتبات بايثون المطلوبة
pip3 install -r requirements.txt

# 4. تشغيل التطبيق (يتطلب صلاحيات الروت لعمل أدوات الشبكة بشكل صحيح)
sudo python3 main.py
```
